## 🚀 Flagship Project / پروژه شاخص

### [Axis Puls (axispuls1)](https://github.com/axispuls/axispuls1)
- 📡 **Real-time File Watcher:** Continuous background directory polling with zero duplication.
- 🗜️ **Smart Multipart Archiver:** Automatic deflate compression and chunking (<=18MB) for strict messenger quotas.
- 🔄 **GitHub Cloud Auto-Updater:** Instant one-click binary update with zero user friction.
